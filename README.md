# Candy Tools
Candy Tools adds usability to several Candy Arts Assets, through a multipurpose UI panel:<br>
• Godot Plugin design for easy setup.<br>
• Can self-update.<br>
• Includes tools for various Candy Arts add-ons for Godot.<br>
• Can download and install Candy Database + any Candy Arts documentation databases.<br>
• Can display Candy Arts news.<br>
• All tools are located in a shared tab in the Godot Editor bottom panel.<br>
• Completely free.

## Supported Add-Ons
At this time, Candy Tools adds functionality to the following assets:<br>
• [Candy Loot](https://candyarts.gumroad.com/l/candyloot)<br>
• [Candy Triggers](https://candyarts.gumroad.com/l/candytriggers)<br>

## Installation
Candy Tools is installed like any regular Godot plugin:
1. Download the source code of the latest release.
2. Unpack/Unzip.
3. Copy the "Candy_Tools" folder to your project's 'addons' folder. If the folder doesn't exist, create it in your project's root folder.
4. In the Godot editor: go to "Project" → "Project Settings" → "Plugins" tab.
5. Enable the Candy Tools plugin.

## Tools
Some tools are only provided with their respective Candy Arts Assets, and must be copied to the '/Candy_Tools/tools' folder.
