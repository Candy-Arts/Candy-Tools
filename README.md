# Candy Tools
Candy Tools adds usability to our assets, through a multipurpose UI panel:<br>
• Includes tools for Candy Loot and Candy Triggers.<br>
• Godot Plugin design for easy setup.<br>
• All tools are located in a shared tab in the Godot Editor bottom panel.<br>
• Does not create any dependency (can be removed at any time).<br>
• Completely free.

## Supported Add-Ons
At this time, Candy Tools adds functionality to the following assets:<br>
• [Candy Loot](https://candyarts.gumroad.com/l/candyloot)<br>
• [Candy Triggers](https://candyarts.gumroad.com/l/candytriggers)<br>

## Installation
1. Download this repository.
2. Access the Godot folder for your Godot version (e.g. "Godot 4.6+").
3. Copy the "Candy_Tools" folder.
4. Go to your Godot project's root folder.
5. If you don't have the "addons" folder, create a new folder and name it "addons" (lowercase)
6. Paste "Candy_Tools" inside the "addons" folder.
7. Open your project in Godot.
8. Go to "Project" → "Project Settings" → "Plugins" tab.
9. Enable the Candy Tools plugin.
10. Restart Godot.

## Tools
Tools are provided with their respective Candy Arts Assets.

Each Asset has a folder for its own tools (e.g. candy\_loot). That folder must be placed in the assets/Candy\_Tools/tools/ folder.
